### Hi, I'm Nadir İbrahimoğlu

Senior Research Engineer at Huawei in Ankara, working on large language models, multi-agent systems and code generation. PhD in Computer Engineering (Karadeniz Technical University). Before Huawei I built biometric authentication systems and on-device ML models in the defence industry, led software teams in enterprise software, and taught computer engineering courses at university level.

**Research interests:** LLM-based code generation, multi-agent systems, LLM evaluation, speech AI, biometrics, IoT security, metaheuristic optimization.

#### Selected work

- **[MAS-ArkTSCode-Dataset](https://github.com/nadir-ib/MAS-ArkTSCode-Dataset)**: 6,034 compiler-verified prompt and code pairs for ArkTS (HarmonyOS). Accompanies the paper *Compiler-Validated Code Generation for ArkTS on HarmonyOS*, Automated Software Engineering, 2026. [DOI](https://doi.org/10.1007/s10515-026-00695-w)
- **[fixed-point-metaheuristics](https://github.com/nadir-ib/fixed-point-metaheuristics)**: code and data for a fixed-point analysis of fractional-order memory in population-based optimization (PSO, Jaya, WFO, ACOR). Every table and figure can be regenerated from the scripts.
- **[pubscope-mcp](https://github.com/nadir-ib/pubscope-mcp)**: remote MCP server that gives AI assistants journal trust scores, quartiles, indexing status and reference verification from [PubScope](https://pubscope.org).
